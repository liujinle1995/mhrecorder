MhRecorder（梦幻西游手游截图记录助手）—— 安装版使用说明
================================================================

版本：见「关于」页或开始菜单里的快捷方式版本
运行方式：完全离线。不联网、不上传任何截图或数据，不使用 GPU，也不做云调用。


一、怎么启动
----------------------------------------------------------------
开始菜单 → MhRecorder，或桌面快捷方式（安装时勾选了才会创建）。

直接双击安装目录里的 MhRecorder.exe 也行：界面发现本地识别引擎没在跑，
会自己启动同目录的 mhservice.exe 并等它就绪。不需要设置任何环境变量，
也不需要再用绿色版那个 run.ps1。


二、数据存在哪里
----------------------------------------------------------------
%LOCALAPPDATA%\MhRecorder\
    mhrecorder.db    角色 / 快照 / 装备 / 背包 / 设置（SQLite，WAL 模式）
    mhservice.log    后端日志（排查"识别不动"时看这个）
    ui.log           界面日志

- 换位置：设置环境变量 MH_DATA_DIR 指向其它目录，再启动程序。
- 备份：关闭程序后复制整个 %LOCALAPPDATA%\MhRecorder 目录。
- 清除：设置 → 清空本地数据，或卸载时在提示里选"是"。


三、安装 / 卸载
----------------------------------------------------------------
- 按用户安装到 %LOCALAPPDATA%\Programs\MhRecorder，不需要管理员权限，
  不写 Program Files，不装系统服务，不写开机自启。
- 卸载：设置 → 应用 → 已安装的应用 → MhRecorder → 卸载，
  或开始菜单里的「卸载 MhRecorder」。
- 卸载默认保留数据库（卸载程序顺手删用户记录是最容易出事的行为）。
  要连数据一起删，在卸载提示里选"是"。


四、常见问题
----------------------------------------------------------------
1) 顶部出现红色横幅"未连接本地识别引擎"
   - 先确认安装目录里 mhservice.exe、onnxruntime.dll、models\ 都在；
   - 直接双击 MhRecorder.exe 会自己拉起后端，如果还是失败，
     看 %LOCALAPPDATA%\MhRecorder\mhservice.log 最后几行；
   - 杀毒软件可能拦截 mhservice.exe（它要创建命名管道），加白名单后再试。

2) 识别一直失败（提示 OCR 不可用）
   - 检查安装目录 models\ 下的三个文件：
     ch_PP-OCRv4_det_infer.onnx / ch_PP-OCRv4_rec_infer.onnx / ppocr_keys_v1.txt
   - 确认 onnxruntime.dll 没被删（缺它整条识别链都起不来）。

3) 提示缺少 VC++ 运行库
   安装 Microsoft Visual C++ 2015-2022 Redistributable (x64)。

4) 首次运行被 SmartScreen 拦住
   安装包未做代码签名（个人项目，签名证书需要付费）。
   「更多信息」→「仍要运行」即可。介意的话可以核对发布页上的 SHA256。


五、关于杀毒软件误报
----------------------------------------------------------------
本项目用 Rust + WinUI 打包，没有加壳、没有联网行为，但：
- 未签名的 exe 在部分杀软里会被标为"未知程序"，属正常现象；
- 若被隔离，请把安装目录整个加入白名单；
- 校验完整性：发布页同时提供 SHA256SUMS 文件，
  PowerShell 里 `Get-FileHash .\MhRecorder.exe -Algorithm SHA256` 对比即可。


六、导出
----------------------------------------------------------------
设置 → 导出全部数据为 JSON，写出完整数据文档（纯本地文件，不上传）。
后端同时支持 CSV / ZIP 导出（ZIP 内含 data.json）。
